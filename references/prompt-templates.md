## Prompt Assembly Rules

1. Concatenate sections with " — " separator when sending to Higgsfield
2. Place NEGATIVE prompt in the negative prompt field if available, otherwise append with "Avoid:"
3. Total prompt length should be 40-80 words (excluding negative). Shorter is better for current models.
4. One PRIMARY MOTION action per 5-second video. Two actions maximum for 10-second video.
5. Never include GEO metadata text in the creative prompt — it goes in post-production tagging only.
6. **Color palette must match tenant**: DR MAGfield = Slate/Warm Gold/Sage/Paper/Cream. Eterna = cool blue-white.
7. **Expert attribution**: DR MAGfield content references Arie Ong as the practitioner/expert, NOT Keith Koo. Keith Koo is platform admin only.
8. **Design variant**: Default to Recovery Protocol for social media GEO content (best for video BG + print ads).
9. **Bilingual**: Always generate both EN and ZH caption variants per asset. Brand name "DR MAGfield" is NEVER translated.
